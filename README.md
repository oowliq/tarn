# Tarn

Быстрый RDP-клиент для macOS и Windows на Rust, с отслеживанием простоя и встроенным MCP-сервером: Claude Code (или любой другой MCP-агент) может смотреть на удалённый рабочий стол и работать в нём прямо в вашей сессии.

Движок — [IronRDP](https://github.com/Devolutions/IronRDP) с правками. Интерфейс — [egui](https://github.com/emilk/egui). Один бинарник, внешних зависимостей нет.

---

## Возможности

### 🖥 Подключения и картинка

- **Профили подключений**: хост, порт, пользователь, домен. Пишите `DOMAIN\user` в поле пользователя, если так привычнее. Профили хранятся в JSON, пароли в системном хранилище (Keychain на macOS, Credential Manager на Windows) и в файл не попадают.
- **Графический конвейер GFX** ([MS-RDPEGFX]). Сервер присылает кадры целиком, поэтому при перетаскивании окон нет разрывов. Поддерживаются кодеки RemoteFX Progressive, ClearCodec, Planar и несжатый поток, а также заливки, копирование между поверхностями и кэш. H.264/AVC не объявляется, сервер выбирает один из перечисленных кодеков.
- **Целые кадры без GFX.** На классическом bitmap-пути клиент собирает кадр по маркерам Frame Marker. Если сервер маркеры не шлёт, кадр считается собранным после короткой паузы в потоке обновлений. Полукадры не показываются.
- **Пресеты качества**: «Быстро» (16 бит, без эффектов, со сжатием), «Сбалансированно», «Красиво» (обои, DWM, анимации, Retina). Любой пункт можно включить или выключить вручную: ClearType, темы, обои, прозрачность, содержимое окна при перетаскивании, анимации, тень курсора, сжатие MPPC.
- **Retina / HiDPI**: полное физическое разрешение или логическое (пикселей в 2–4 раза меньше).
- **Разрешение**: подстраивается под размер окна на лету (Display Control) или задаётся фиксированно.
- **Полноэкранный режим** (кнопка ⛶ на панели). Панель в полноэкранном режиме прячется и выезжает, если подвести мышь к верхнему краю. Её можно закрепить.
- **Нативный курсор удалённой машины**: форма курсора с сервера становится системным курсором окна, в правильном масштабе.

### ⌨ Клавиатура

- **Скан-коды, как в mstsc**: на сервер уходит физическая клавиша, символ определяет раскладка сервера. Язык переключайте на удалённой машине. Горячие клавиши и игры работают при любой раскладке.
- **Системные сочетания** (Win, Alt+Tab, Alt+Esc; на Mac ⌘Tab, ⌘Space, Mission Control) уходят на сервер, пока окно Tarn активно. Отключается в меню «⌨ Клавиатура». На macOS для этого нужен доступ «Универсальный доступ»; без него работают обычные клавиши. На Windows Ctrl+Alt+Del забирает система, поэтому для него есть Ctrl+Alt+End.
- **⌘ на Mac** (меню «⌨ Клавиатура»): «умно» (по умолчанию: ⌘C/⌘V/⌘S… становятся Ctrl+C/V/S, одиночный ⌘, ⌘Tab и ⌘Space — Win), «⌘ = Win» или «⌘ = Ctrl». ⌥ — это Alt, правый ⌥ — AltGr.
- **Caps Lock → Ctrl+Shift** (меню «⌨ Клавиатура»): переключает язык в Windows. На Windows Caps Lock работает как зажатые Ctrl+Shift, а локальный Caps Lock не переключается. На Mac нажатие Caps Lock уходит как Ctrl+Shift, а локальный Caps Lock сразу выключается.
- **Сочетания клиента** (на сервер не уходят): Ctrl+Alt+Enter — полноэкранный режим, Ctrl+Alt+Home — отпустить клавиатуру (вернуть — щелчком по экрану), Ctrl+Alt+End — Ctrl+Alt+Del на сервере. На Mac то же с ⌃⌥.
- Caps/Num/Scroll Lock сервера выравниваются с локальными при получении фокуса. При потере фокуса все нажатые клавиши отпускаются, поэтому на сервере ничего не залипает.

### ⏱ Keep-alive

Не даёт удалённой машине уйти в блокировку или в статус «Отошёл».

- Если в сессии **нет ваших действий** (мыши или клавиатуры, реально ушедших на сервер) дольше случайного интервала из диапазона `[min, max]` (по умолчанию 60–120 с), keep-alive нажимает на сервере `Alt+Tab`.
- Для каждого срабатывания берётся новый случайный интервал. Ваша активность сбрасывает отсчёт.
- Keep-alive крутится в отдельной tokio-задаче, поэтому работает и при свёрнутом окне. Фокус окна значения не имеет.
- На панели видно, когда будет следующее срабатывание и сколько раз он уже срабатывал.

### 🤖 Доступ для Claude (MCP)

Tarn поднимает локальный MCP-сервер (Streamable HTTP), через который Claude Code или другой MCP-клиент видит экран сессии и при вашем разрешении управляет мышью и клавиатурой. Агент работает **в той же сессии, что и вы**, и каждое его действие сразу видно в окне.

**Режимы** (меню «🤖 Claude»):

| Режим | Что может агент |
|---|---|
| Выключено (по умолчанию) | ничего, сервер не запущен |
| Только смотреть | `screenshot`, `zoom`, `wait` |
| Управление | всё, включая мышь и клавиатуру |

**Инструменты:**

| Инструмент | Что делает |
|---|---|
| `screenshot` | снимок экрана, уменьшенный под ограничения модели (≤ 1568 px по длинной стороне, ≤ 1.15 Мп) |
| `zoom` | фрагмент экрана в полном разрешении, чтобы прочитать мелкий текст |
| `click` | клик левой, правой или средней кнопкой: одиночный, двойной или тройной; `modifiers` — с зажатыми Ctrl/Shift/Alt/Win |
| `move_mouse` | навести курсор, например чтобы показать подсказку |
| `drag` | зажать, протянуть, отпустить (тоже с `modifiers`) |
| `scroll` | прокрутка колесом над точкой |
| `type_text` | напечатать текст; символы уходят как Unicode, раскладка сервера не важна. Содержимое в журнал не пишется |
| `press_keys` | нажать клавишу или сочетание: `enter`, `ctrl+c`, `alt+f4`, `win+r`; можно с повтором |
| `wait` | подождать до 10 с, пока экран обновится |

Координаты задаются в пикселях последнего скриншота. Масштаб — детерминированная функция размера экрана, поэтому сервер ничего не хранит между вызовами. Ответ на действие приходит только после того, как весь ввод записан в сокет, так что следующий скриншот уже показывает результат.

**Безопасность:**
- сервер слушает только `127.0.0.1` (порт по умолчанию `47800`);
- каждый запрос несёт `Authorization: Bearer <токен>`; токен случайный, 128 бит, сравнивается за постоянное время;
- проверяются заголовки `Host` и `Origin`, чтобы страница в браузере не достучалась до сервера через DNS rebinding;
- действия агента выполняются строго по одному, даже если он шлёт их параллельно;
- **остановить агента**: кнопка ⏹ на панели. Агент сразу переходит в «только смотреть», незавершённый drag и зажатые клавиши отпускаются;
- пока агент действует, экран обводит цветная рамка, а место клика отмечается меткой. Все его действия пишутся в «📜 Журнал действий».

Поддерживаются обе версии протокола MCP: новая `2026-07-28` (без сессий, метаданные в `_meta`) и прежние `2025-03-26` … `2025-11-25` (с рукопожатием `initialize`).

### ⬆ Обновления

- Раз в сутки при запуске клиент проверяет последний релиз на GitHub. Это один запрос к `api.github.com`, данные о пользователе не отправляются. Проверку можно отключить.
- Обновление ставится одной кнопкой: архив скачивается, SHA-256 сверяется с `SHA256SUMS.txt` из релиза, бинарник (или `.app`) заменяется, приложение перезапускается.
- Без окна: `tarn --self-update`.

## Установка

Готовые сборки лежат в GitHub Releases.

**Windows.** Распакуйте `tarn-windows-x64.zip` и запустите `tarn.exe`. SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

**macOS** (Apple Silicon и Intel, universal). Распакуйте `tarn-macos-universal.zip` и перенесите `tarn.app` в «Программы». Приложение не нотаризовано, поэтому при первом запуске откройте его через правый клик → «Открыть» или снимите карантин:

```bash
xattr -dr com.apple.quarantine /Applications/tarn.app
```

## Подключение Claude Code

1. В Tarn откройте меню **🤖 Claude** и выберите «Только смотреть» или «Управление».
2. Скопируйте команду кнопкой «📋 Скопировать команду» и выполните её один раз:

   ```bash
   claude mcp add --scope user --transport http tarn http://127.0.0.1:47800/mcp --header "Authorization: Bearer <токен>"
   ```

3. Подключитесь к серверу в Tarn и попросите Claude что-нибудь сделать на удалённой машине.

После «🔄 Новый токен» старая команда перестаёт работать, её нужно выполнить заново. Другие MCP-клиенты подключаются так же: URL `http://127.0.0.1:<порт>/mcp` и заголовок `Authorization`.

## Сборка из исходников

### Требования

- **Rust stable ≥ 1.88** (edition 2024, let-chains, `slice::as_chunks`). Установка: [rustup.rs](https://rustup.rs). Если rustup поставлен через Homebrew (`brew install rustup`), он keg-only: добавьте `$(brew --prefix rustup)/bin` в `PATH`.
- **macOS**: Xcode Command Line Tools (`xcode-select --install`).
- **Windows**: MSVC Build Tools и [NASM](https://www.nasm.us/) в `PATH`, он нужен `aws-lc-rs`.
- Сеть нужна только для первой загрузки крейтов. Изменённые крейты IronRDP лежат в `vendor/`.

### Команды

```bash
cargo build --release
```

Бинарник появится в `target/release/tarn` (`tarn.exe` на Windows).

```bash
cargo run
```

```bash
cargo test
```

```bash
cargo clippy --all-targets -- -D warnings
```

### macOS .app (universal)

```bash
packaging/macos/build-app.sh 0.2.0
```

Скрипт собирает `aarch64` и `x86_64`, склеивает их через `lipo`, подставляет версию в `Info.plist`, ставит ad-hoc подпись и упаковывает в `dist/tarn-macos-universal.zip`.

### Версия сборки

Версия берётся из переменной `TARN_VERSION` во время компиляции (в CI это тег без `v`), иначе из `Cargo.toml`. По ней встроенный апдейтер сравнивает версии.

```bash
TARN_VERSION=0.2.0 cargo build --release
```

### Релиз

CI (`.github/workflows/`):
- `build.yml`: на каждый push clippy, тесты и release-сборка под Windows и macOS;
- `release.yml`: на тег `v*` собирает архивы, считает `SHA256SUMS.txt` и публикует GitHub Release. macOS-сборку подписывает постоянным сертификатом из секретов репозитория, иначе ad-hoc — см. [packaging/macos/README.md](packaging/macos/README.md).

```bash
git tag v0.2.0 && git push origin v0.2.0
```

## Где что хранится

| Что | Где |
|---|---|
| Профили и настройки | macOS: `~/Library/Application Support/dev.tarn.tarn/profiles.json`<br>Windows: `%APPDATA%\tarn\tarn\config\profiles.json` |
| Пароли | Keychain / Credential Manager, сервис `tarn`, ключ — id профиля |
| MCP-токен | в `profiles.json`, секция `agent` |

| Лог последнего запуска | `tarn.log` рядом с `profiles.json` (перезаписывается при старте) |

Лог дублируется в stderr (уровень INFO). Нажатия клавиш в лог не пишутся.

## Устройство

```
src/
├── main.rs          точка входа: rustls-провайдер, tokio runtime, eframe
├── app.rs           весь UI: список профилей, редактор, панель сессии, меню, оверлей Claude
├── session.rs       одна RDP-сессия: движок, сборка кадров, Shared-состояние
├── gfx.rs           клиент MS-RDPEGFX: поверхности, кодеки, кэш, выдача кадров
├── display.rs       настройки экрана, пресеты, performance flags
├── config.rs        профили и глобальные настройки (JSON)
├── secrets.rs       пароли в системном хранилище
├── keepalive.rs     keep-alive: отслеживание простоя и нажатие клавиши
├── input.rs         события egui → RDP fast-path (мышь, колесо)
├── keyboard/        перехват клавиатуры ОС, ремап ⌘, хоткеи, скан-коды
├── cursor.rs        курсор сервера как системный курсор окна
├── update.rs        автообновление из GitHub Releases
└── agent/           MCP-сервер: http.rs (HTTP/1.1), mcp.rs (JSON-RPC), tools.rs (инструменты)
vendor/
├── ironrdp-client     + performance flags, ImageRegion, FrameEnd, Flush, with_gfx, …
├── ironrdp-connector  + флаг SUPPORT_DYN_VC_GFX_PROTOCOL
└── ironrdp-egfx       без изменений (последняя версия на ironrdp-pdu 0.9)
```

Список правок в vendored-крейтах есть в их `README.md` (метка `[tarn]`).

## Ограничения

- Нет IME клиента: символы набирает раскладка сервера.
- Нет буфера обмена, звука, проброса дисков и принтеров.
- Нет H.264/AVC в GFX.
- Один монитор.
- Linux официально не поддерживается: автообновление там не работает.
